### Fixed

- On a Bun host the LSP tools now start the builtin TypeScript language server and its `tsserver` with that Bun instead of the `node` found on PATH (#11757). With the lean defaults from #11756 a TypeScript session measured 236-245 MiB instead of 290-296 MiB. Node hosts, other language servers, and any `typescript` entry that sets its own `command` are unchanged; a command that cannot be resolved is passed through as before. ([#11758](https://github.com/code-yeongyu/oh-my-openagent/pull/11758))
- The LSP tools now start the TypeScript language server without its syntax-only `tsserver` and `typingsInstaller` (#11755). A TypeScript session runs two processes instead of four (measured 292 MiB instead of 597 MiB on a small project). Set `initialization` for `typescript` in `lsp-client.json` to restore the old options; a builtin's defaults now reach `initialize` and user or project keys override them. ([#11756](https://github.com/code-yeongyu/oh-my-openagent/pull/11756))
