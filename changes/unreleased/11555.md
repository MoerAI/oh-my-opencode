**Installers and the OmO Native first-run notice now describe telemetry.** `install.sh`, `install.ps1`, `bunx oh-my-openagent install`, `lazycodex-ai install` and `omo setup` end with a short notice: what anonymous usage telemetry contains, that it goes to PostHog in the United States, how to turn it off (`DO_NOT_TRACK=1` or `OMO_DISABLE_TELEMETRY=1`), and a link to the privacy policy. The one-time OmO Native notice names the same destination, both opt-outs (including `"telemetry": { "enabled": false }` in `~/.omo/omo.jsonc`) and the privacy policy. ([#11608](https://github.com/code-yeongyu/oh-my-openagent/pull/11608))

**Echo argv no longer earns a test receipt.** Claim receipts keep runner argv as one invocation and read a `[name, command]` pair only in its nested-pair position. Genuine test argv and nested command pairs still count. ([#11542](https://github.com/code-yeongyu/oh-my-openagent/pull/11542)) Thanks to [@MoerAI](https://github.com/MoerAI).

**Ordinary thread mutations preserve attachment refusal codes.** A vanished session or a selected durable identity that does not match the live routing id now raises a typed error carrying `unknown_session` or `session_identity_mismatch`, without sending the mutation or releasing an attachment. ([#11533](https://github.com/code-yeongyu/oh-my-openagent/pull/11533)) Thanks to [@MoerAI](https://github.com/MoerAI).

**A failed facts-file park move can now recover in the same process.** Once the filesystem is repaired, ordinary queue operations retry cold-storage migration without changing parked state or payload bytes. Successful movement keeps its existing migration cache. ([#11522](https://github.com/code-yeongyu/oh-my-openagent/pull/11522)) Thanks to [@MoerAI](https://github.com/MoerAI).

**Time-boxed memory stops being injected once it expires.** A memory file can declare `expires: <ISO 8601>` in its frontmatter (a UTC date, or an instant with `Z` or an offset). From that instant the `system/` block is no longer projected into new sessions. The compile cache recompiles at the instant, and a session already running keeps its pinned prompt and gets one notice that the block has expired. Expired files are never deleted; reflection and dream move them to `reference/`. ([#11458](https://github.com/code-yeongyu/oh-my-openagent/pull/11458))

**Kimi K3.1 Pro is the default Kimi model.** Every built-in chain and the Daily · Normal model profile that ran Kimi K3 now runs Kimi K3.1 Pro (`kimi-k3.1-pro`, `k3.1-pro` on Kimi Code) on Kimi Code, Moonshot, Moonshot CN and OpenCode Go. OpenCode Zen, Bailian, Firmware, Ollama Cloud and AIHubMix do not serve K3.1 Pro yet, so they keep Kimi K3 on a rung right after it. Kimi K3.1 Pro and K3.1 Pro Highspeed get capability entries (1M context), telemetry reports them by name, and the fallback notice calls the model "Kimi K3.1 Pro". ([#11451](https://github.com/code-yeongyu/oh-my-openagent/issues/11451)) ([#11455](https://github.com/code-yeongyu/oh-my-openagent/pull/11455))

Windows reflection deadlines now terminate the model's entire process tree, preventing descendants from continuing after a run times out. ([#11382](https://github.com/code-yeongyu/oh-my-openagent/pull/11382)) Thanks to [@AgentSMLA](https://github.com/AgentSMLA).

**Delegated child sessions retain their spawn ancestry.** OmO passes the parent
session, root session, and task identity through in-process, daemon-hosted, and
standalone RPC launches, including respawns. Standalone children receive
`--spawned-by`, and daemon-hosted children send `open_session.spawnedBy`, only
when the engine that runs them is senpi 2026.10.24-4 or later (the first release
with senpi#4205); an older or unidentifiable engine, including a custom
`SENPI_BIN`, starts the child without ancestry instead of failing it. Part of
#10782. ([#11298](https://github.com/code-yeongyu/oh-my-openagent/pull/11298))

**Desktop thread tools are available to agents in their own session.** When the app offers its thread toolkit, OmO acquires the session's grant without blocking session startup and registers valid, non-conflicting tools with a `desktop_` prefix, including `desktop_thread_organize`. If discovery fails, it retries in the background without holding a turn, so the tools can appear partway through one; retries back off (the next turn, then two and four turns later) and stop after three; shutdown cancels discovery and clears the grant. Calls use only the calling session's grant and read its bearer from the credential file at call time. Sessions without a grant register no desktop thread tools. The dependency-free HTTP client loads only for offered toolkits, keeping desktop integration out of other sessions' startup. ([#11217](https://github.com/code-yeongyu/oh-my-openagent/pull/11217))

Thread parent, root, and task identity through child-session creation and
