**A new Next.js page's route-segment config no longer trips knip.** Exports Next.js reads by name from the web app's page, layout and route files (`revalidate`, `dynamic`, `generateMetadata`, `metadata`, ...) were each silenced by their own per-symbol row, so the next page that set one turned the check red. knip now recognises them from a scoped config for those files, while every other export of the same file stays checked.
